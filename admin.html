スタッフ画面を開く

洗車スタッフ・予約受付スタッフ一人ひとりの ID とパスワードです。スタッフ画面で「スタッフID」と「パスワード」を入れて入ります。辞めた人は削除するだけで入れなくなり、ほかの人のパスワードは変えなくて済みます。操作ログにも、誰が予約を入れた・取り消したかが残ります。

ID は半角の英小文字・数字・. _ - で3文字以上。決めたパスワードは本人に直接伝えてください(保存後は管理画面でも見られません)。

共通のスタッフ用パスワード(任意)

ID を持たないスタッフが、全員同じパスワードで入るためのものです。全員に上の ID を配ったら、外すことをお勧めします(共通パスワードは、人が辞めるたびに変える必要があります)。お客様の電話番号なども見られるので、使う場合は6文字以上にしてください。

サーバー(Code.gs)の更新が必要です。

登録が早い順です。「通知中」は空き枠を確保して案内メールを送った状態で、保留時間を過ぎると次の方へ移ります。

「設定」タブの「サイトURL」が空欄です。キャンセル待ちの案内メールに確定用のリンクが入りません。お客様画面のURLを入れて保存してください。
サーバー(Google Apps Script)のコードが古いため、この画面は使えません。新しい Code.gs を貼り付けて、デプロイし直してください。

受付する開始時間

押すと切り替わります。黒い時間だけ、お客様が開始時間として選べます。洗車時間ぶんの空きがない時間や、昼休憩にかかる時間は自動で受け付けません。

この日だけ変則

特定の日だけ、開始時間を変えられます(台ごとに分けている場合も、その日は全部の台がこの時間になります)。「決定」を押すとすぐ保存されます。

お知らせを通知で送る

お客様のスマホのアプリ(ホーム画面に追加し、通知をオンにした方)へ、すぐに通知を送ります。臨時休業など、急ぎのお知らせに使ってください。送った通知は取り消せません。

車種

「大型」にチェックした車種は、洗車時間が長くなります。左の つまみ を長押しして上下に動かすと、お客様の画面に出る順番を変えられます。

担当スタッフ

お客様が予約のときに選べる担当スタッフです。店舗ごとにまとめて登録します(お客様の画面でも店舗ごとに分けて表示します)。つまみを長押しして上下に動かすと、店舗の中での並び順を変えられます。

月を選んで日付をタップするとお休み/営業が切り替わります(自動保存)。曜日名をタップすると、その月の同じ曜日をまとめて切り替えます。お休みがない月も「この月を確定」を押してください。先1年ぶんまで設定でき、今月〜3か月先が未確定のあいだは毎日管理者メールにお知らせが届きます。

画面の文章

お客様の画面と同じ見た目です。点線で囲まれた文字を押すと、その場で書き換えられます。書き換えたら下の「文章を保存する」を押してください。

お客様の画面に出る文字の一覧です(ボタン・見出し・お知らせなど、すべて)。画面ごとに並んでいます。上の欄で探せます。
薄い字は最初の文です。空欄に戻すと最初の文が使われます。{〜} の部分はお客様の画面で実際の値に置き換わるので、消さないでください。

メールの文章

お客様に届くメールです。下のタグを押すと、カーソルの位置に差し込み項目が入ります(送るときに、お名前や日時などに置き換わります)。件名の前には自動で【店名】が付きます。本文を空にすると、最初の文章に戻ります。

読み込み中…通信に数秒かかることがあります。そのままお待ちください。
